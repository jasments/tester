BROOKS COASTAL CLEANING — WEBSITE
=================================

A bespoke, responsive one-page website styled around the Brooks Coastal Cleaning flyer.

OPEN THE WEBSITE
1. Unzip the download.
2. Open the "Brooks-Coastal-Cleaning" folder.
3. Double-click "index.html" to open in Safari or another browser.
4. Keep the "assets" folder next to index.html.

FILES
index.html     — All website content and page structure.
styles.css     — Colours, typography, layout and responsive design.
script.js      — Mobile menu, service selection, FAQ / quote functionality.
assets/        — Optimised web images and Brooks logo extracted from the supplied flyer.

BEFORE PUBLISHING
- IMPORTANT: Confirm the phone number 07712 345678 and email
  hello@brookscoastalcleaning.co.uk shown on the flyer are correct and live.
- The quote form currently opens a pre-filled email in the visitor's email
  app. This is intentional for an offline/static preview; it does not send
  submissions automatically or store customer details.
- For a live website, connect the form to a production form service or
  Vercel serverless endpoint so visitors can submit without an email app.
- Review all service descriptions and coverage areas for accuracy.
- The supplied flyer and earlier screenshot imagery are used as reference/
  demo assets. Replace gallery/example pictures with your own confirmed
  business photographs before launching if necessary.
- Fonts load from Google Fonts when connected to the Internet; a local
  serif/sans-serif fallback is used offline.

DEPLOYING
The site is plain HTML, CSS and JavaScript. It can be deployed to Vercel,
Netlify, Cloudflare Pages or GitHub Pages. Upload all files and assets
maintaining the same folder hierarchy.

No frameworks, build tools or package installs required.
